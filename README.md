## 3. Ключові сценарії та оновлення даних

### Сценарій 1: Додавання товару до кошика та оформлення замовлення

- **Клієнт**: Користувач обирає товар у каталозі (`catalog.js`) та натискає «Купити». Товар додається до локального стану кошика та зберігається в `localStorage`.
- **Клієнт**: На сторінці оформлення (`checkout.html`) користувач заповнює контактні дані та адресу доставки, після чого клієнт надсилає POST-запит на `/api/orders` через `api.js` з масивом товарів та даними користувача.
- **Сервер** (`server.js` -> `orderController.js`):
- Валідує вхідні дані.
- Створює документ у колекції `orders`.
- Оновлює залишки товарів (зменшує `stock`) у колекції `products` за допомогою оператора віднімання в MongoDB.

- **База даних**: Оновлює документи в колекціях `products` та створює новий документ у `orders`. Повертає успішну відповідь клієнту.

### Сценарій 2: Керування товарами адміністратором (CRUD)

- **Клієнт**: Адміністратор через панель (`admin.html`) надсилає форму для створення нового товару (POST-запит на `/api/products`).
- **Сервер** (`productController.js`): Зчитує тіло запиту через обробку потоків (streams) нативного Node.js, перевіряє наявність обов'язкових полів.
- **База даних**: Нативний драйвер MongoDB виконує метод `insertOne()` у колекцію `products`.
- **Клієнт**: Отримує підтвердження та оновлює список товарів на сторінці в реальному часі.
